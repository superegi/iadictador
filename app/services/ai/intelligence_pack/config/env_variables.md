# Variables de entorno IA Dictador

No guardar secretos aquí. Solo nombres y propósito.

## Modelos
- IAD_AI_MODEL_AUDIO_FIRST_SMART_EDITOR
  Modelo específico para editor inteligente de plantilla.

- IAD_AI_MODEL_AUDIO_FIRST_TEMPLATE_BRIDGE
  Modelo para puente audio-first + plantilla.

- IAD_AI_MODEL_TEXT_STRUCTURED
  Modelo para extracción estructurada.

- IAD_AI_MODEL_TEXT
  Modelo textual general.

## Activación
- IAD_SMART_TEMPLATE_EDITOR
  1 activa el editor inteligente.
  0, false, no, off lo desactivan.

## Secretos
- API keys y credenciales deben vivir en .env o secrets de Docker.
- No deben exportarse dentro del intelligence pack.
