# Examples / Few-shots

Aquí deben guardarse ejemplos transferibles.

Formato recomendado: JSONL, una línea por caso.

Campos sugeridos:
- template_name
- dictation
- clinical_json
- template_before
- model_report
- doctor_corrected_report
- notes

Estos ejemplos permitirán recuperar tu estilo de corrección y transferirlo a otro modelo.
