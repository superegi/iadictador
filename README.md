# Reporte IA Prototype

Prototipo aislado para informes médicos asistidos por IA.

Objetivo inicial:
- Cargar plantilla clínica desde YAML.
- Procesar texto dictado/escrito.
- Generar informe marcado con colores.
- Generar informe limpio final.

Fases:
1. Reglas simples sin IA.
2. IA con JSON estructurado.
3. Voz con Whisper/local o API.
4. Integración con NeuroPACS.
